# 🎮 NES 游戏在线模拟器

一个基于 [EmulatorJS](https://emulatorjs.org/) 构建的 NES（FC）游戏在线模拟器网页。内置游戏目录侧边栏，支持从预设列表选择游戏，或上传本地 `.nes` 文件即时游玩。

---

##  功能特性

-  **内置游戏目录**：预置大量经典 FC 游戏（勇者斗恶龙、最终幻想、吞食天地、重装机兵、第二次机器人大战等），一键加载
-  **本地上传**：支持上传本地 `.nes` 文件，自动校验 NES 文件头（`4E 45 53 1A`），非法文件会被拒绝
-  **侧边栏目录**：可折叠的侧边游戏目录，游戏加载后自动隐藏，左上角菜单按钮可随时唤出
-  **游戏切换**：返回游戏选择界面后可清空当前实例并重新选择游戏
-  **深色主题 UI**：卡片式设计、渐变按钮、状态徽章动画、响应式布局适配移动端
-  **移动端适配**：针对 640px / 400px 断点优化布局

##  快速开始

### 1. 本地运行

由于需要读取本地 ROM 文件，**不能直接双击打开 `index.html`**（`file://` 协议下会有跨域限制）。请使用任意静态服务器：

```bash
# 使用 Python
python -m http.server 8080

# 或使用 Node.js (http-server)
npx http-server -p 8080

# 或使用 VS Code Live Server 插件
